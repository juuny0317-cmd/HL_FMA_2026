# HL Mando Course 07 본선 TUI

건국대 시험 TUI와 별도이다. `mando_competition_gps.yaml`의 용인 Course 07 datum과 시험장 원본 ENU 경로를 그대로 사용하며, `R`을 눌러도 좌표계나 경로를 현재 위치로 옮기지 않는다. 새 스택은 현재 RTK 위치와 헤딩으로 차량 전방의 가장 가까운 원본 경로 지점을 찾아 해당 FSM부터 시작한다.

## 실행

```bash
cd /home/yongjun/Competitions/2026/02_HL_FMA_1_5/HL_KU
./operations/run_mando_competition_tui.sh
```

다른 노트북에서 NUCLEO 포트 이름이 다르면 실행 전에 지정한다.


실행 전 파일 검사만 할 때는 다음 명령을 사용한다. 이 명령은 차량을 구동하지 않는다.

```bash
./operations/run_mando_competition_tui.sh --check-config
```

## 시나리오

1. **본선 전체주행**: Course 07 P1/T1/F1 기준 697.803 m. 평행주차 공통 진입은 원본 CSV의 중간 지점부터 시작하고, P1·P2 후진/출차는 각각 CSV의 경로를 사용한다. 경사는 진입~정지선 40 PWM, 정지 유지 10 PWM, 정지 후 HILL 종료까지 30 PWM을 사용한다. 굴절, S자 LiDAR 회피, T/평행 주차 자동선택, 신호, 더미 LiDAR 정지와 종료 구간의 FSM도 포함한다.
   경사 정지 이벤트는 P1/T1/F1 기준 `s=32.6405 m`이며 기존 `34.1405 m`보다 출발지에 1.5 m 가깝다. 정지 유지 시간은 3초다.
   신호등 구간에서는 빨강·노랑·초록·좌회전을 각각 한 프레임에서 즉시 확정한다.
2. **손가락 주행**: 건국대 TUI와 같은 수동 주행이다. RTK 없이 실행할 수 있고, 시작값과 키 한 번의 증감값은 10 PWM이다. `W`/`S`는 구동 PWM을 10씩 누적하고, `A`/`D`는 조향을 한 단계씩 누적한 위치에 고정한다. `SPACE`는 구동 정지, `Q`는 TUI 복귀다.

기능점검용 굴절·S자 단독 시나리오와 경사 PWM 시험 시나리오는 본선 TUI 메뉴에서 제거했다. 기존 경로 파일은 분석 기록으로 남아 있지만 TUI에서 선택하거나 실행하지 않는다. 전체주행 안의 굴절·S자·경사 미션은 그대로 실행된다.

## 현장 실행 순서

1. 차량 전원, UM982, NTRIP 인터넷, 카메라, RPLIDAR, NUCLEO를 연결한다.
2. TUI를 실행하고 RTK가 `FIXED`, heading이 `OK`, `/scan`이 `수신`인지 확인한다.
3. 숫자 `1`로 본선 전체주행을 선택한다. 출발 거리 제한은 없으며 현재 RTK 위치에서 차량 진행 방향 앞쪽의 가장 가까운 경로와 해당 FSM을 찾는다.
4. 필요하면 `V`로 전체주행의 기본 구동 PWM을 입력한다.
5. `R`로 스택을 준비한다. `출발 조건: 완료`가 표시된 뒤 `SPACE`로 출발한다.
6. `SPACE`는 일시정지/재개, `X`는 비상정지, `S`는 스택 종료다. 필요할 때만 `B`로 MCAP 기록을 시작한다.
7. 전체주행의 경사는 시작부터 정지선까지 40 PWM, 정지 유지 시작값 10 PWM, 정지 후 HILL 구간 종료까지 30 PWM이다. 정지선 브레이크 중 차량이 뒤로 밀리면 완전 정지를 기다리지 않고 유지 PWM을 적용하며, 0.04 m/s 이상 후진이 2초 계속되면 유지 PWM을 3씩 올린다. 차량이 실제 정지 범위에 들어온 뒤 3초를 채우면 30 PWM으로 출발한다. 시작 유지값만 바꾸려면 `Q`로 TUI에 돌아와 숫자 `1`, `H`, 원하는 PWM을 입력한 뒤 `R`, `SPACE` 순서로 진행한다. `H=0`이면 기존 브레이크 정지를 사용한다.
8. 손가락 주행은 숫자 `2`, `R`로 들어간다. `W`/`S`로 구동 PWM, `A`/`D`로 조향을 누적 조절하고 `SPACE`로 구동을 정지한다. 손가락 주행은 RTK를 기다리지 않는다.

## 중간 재시작

- 같은 스택에서 `SPACE`로 일시정지/재개하면 기존 진행점과 FSM을 유지한다.
- 전원·fault 때문에 스택을 완전히 다시 띄울 때는 `S`, 필요하면 `G`, 시나리오 번호, `R` 순서로 준비한다.
- 새 스택은 RTK 위치와 헤딩을 이용해 전체 P/T/F 경로군에서 차량 전방의 가장 가까운 경로를 한 번만 선택한다. 차량 뒤 waypoint로 돌아가지 않는다.
- 본선 전체주행의 TUI 출발 거리 제한은 `0`(제한 없음)이다. 경로에서 떨어진 위치도 가장 가까운 전방 waypoint와 해당 FSM을 잡지만, 차량 헤딩이 경로 진행 방향과 맞지 않으면 반대 방향 오진입을 막기 위해 출발하지 않는다.
- 직전 진행점은 `~/.local/state/hl_ku/route_progress.json`에 저장된다. 주차 전진·후진 경로가 같은 위치에 겹쳐도 스택 또는 노트북 재실행 시 직전 단계와 선택 경로를 복원하며, 차량을 2 m 넘게 옮겼거나 기록이 1시간보다 오래되면 이 기록을 버리고 현재 위치에서 다시 찾는다.
- 선택된 경로의 진행거리, 전진/후진 단계, 미션 구간을 복원한다. 경사 정지점을 이미 지난 위치에서는 `HILL_STOP`을 다시 실행하지 않는다.
- 정상 주행이 시작된 뒤에는 직전 진행점부터 짧은 앞쪽 범위만 검색하므로 가까이 겹치는 다른 코스로 진행점이 건너뛰지 않는다.

## 키

- `1~2`: 시나리오 선택
- `V`: 경로 PWM 또는 수동 주행 PWM 증감값 설정
- `H`: 1번 전체주행의 경사 정지 유지 PWM 설정
- `R`: 선택 시나리오 준비
- `SPACE`: 자동주행 출발/일시정지, 수동주행에서는 정지
- `B`: MCAP 기록 시작/종료
- `G`: RTK 확인 스택 재시작
- `X`: 비상정지
- `S`: 현재 ROS 주행 스택 종료
- `Q`: 종료 또는 수동주행에서 TUI 복귀

## 전체주행 확인 항목

기능점검용 단독 메뉴는 제거했으며 `course_07_mission.csv`의 전체 경로와 미션 구간은 그대로 유지한다. 출발 전 Foxglove에서 현재 위치, 카메라, `/scan`, mission state를 확인한다. 주행 중에는 S자 회피, T/P 주차 분기, 신호등, 더미 구간의 3 m LiDAR 정지 및 종료 경로 선택 상태를 함께 본다. 새 P1/P2 경로의 주차 구획 여유 폭과 분기·전진/후진 전환은 저속으로 확인한다.
